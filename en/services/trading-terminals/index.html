01 / TRADING

Trading terminals and market-data platforms

A terminal is not a dashboard with a chart. It is a data pipeline that must not drop a candle when a client's connection blinks. We build the whole thing: exchange connectors through to a fast frontend.

Discuss the taskPackages and pricing

What we do

  • Market-data connectors: REST and WebSocket, reconnect logic, candle resampling
  • Normalisation and a single storage schema for history
  • Realtime transport: WebSocket gateway, fan-out to hundreds of clients, hot-instrument cache
  • Terminal UI: candlestick charts, indicators, order book, ticker, watchlist, layout system
  • Price and event alerts, history and data export
  • Data-stream monitoring, latency metrics, load testing

Who it is for

  • Brokers and exchanges that need their own terminal, not a white label
  • Prop trading desks and analytics services with realtime data
  • Product teams with a prototype but no durable architecture
  • Fintech products that need a market-data layer for their own scenarios

Scope of work

  • Discovery: trader scenarios, data sources, latency requirements
  • Architecture: ingest → bus → storage → realtime → UI, plus the data schema
  • Two-week sprints with a demo at the end of each
  • Load testing and an operations runbook
  • Handover of code, infrastructure and documentation

FAQ

Common questions

Do you connect to exchanges and trading APIs?
Yes, to market data and trading APIs using the client's keys. We only build trading actions when the client holds the required licences and permissions; licences, exchange fees and legal matters stay on the client's side.
What load do you test against?
We fix the target on discovery: instrument count, update frequency, concurrent connections. The load test checks that exact profile, not an abstract “million messages”.
We already have a frontend prototype. Can you take over?
Yes. We usually start with a 1–2 week prototype and architecture audit. Then we either fill in data and realtime, or rewrite the critical layer while keeping what works.
